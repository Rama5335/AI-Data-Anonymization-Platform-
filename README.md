# AI Destekli Güvenli Veri Anonleştirme Platformu

## Proje Hakkında

Bu proje, veritabanlarında bulunan hassas verilerin test ve geliştirme süreçlerinde güvenli şekilde anonimleştirilmesini kolaylaştırmak amacıyla geliştirilmektedir.

Platform; hassas verilerin tespit edilmesi, sınıflandırılması, kullanıcı onayı alınması ve güvenli şekilde anonimleştirilmesi süreçlerini tek bir web uygulaması üzerinden yönetmeyi amaçlamaktadır.

## Proje Durumu

Proje geliştirme aşamasındadır.
